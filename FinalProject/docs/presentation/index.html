13 · design for failure

Mỗi failure mode đều có response + signal + recovery path

422

Input sai schema

Pydantic chặn trước model. Không để request lỗi làm bẩn inference path.

SIGNAL → HTTP metric / validation count
503

Model chưa nạp

Readiness chuyển NOT READY; request không nhận kết quả giả.

SIGNAL → ModelNotLoaded
DEGRADED

MLflow unavailable

Model đang chạy tiếp; cold start dùng local fallback nếu có.

SIGNAL → ModelServedFromFallback
GATE FAIL

Challenger kém

Không promote. Champion tiếp tục phục vụ; pipeline gửi alert.

SIGNAL → RetrainFailed / keep champion
Đây là slide reliability. Mục tiêu là chứng minh “failure is a first-class design concern”. Không có case nào chỉ được ghi log rồi bỏ đó.

16 · what broke when we operated it

Bài học đến từ vận hành thật, không phải từ notebook

01

Evidence phải sinh từ pipeline

Report, model card và docs lấy số liệu từ artifact; retrain xong tài liệu không lệch khỏi hệ thống.

02

Fallback phải observable

Degraded mode mà không có metric + alert chỉ là lỗi bị che giấu.

03

Observability cũng có resource budget

Grafana từng chạm giới hạn memory; dashboard không mở được cho tới khi tăng budget và giảm plugin.

04

Automation phải có guardrail

Drift không được nối thẳng vào auto-promotion; cần cooldown, champion/challenger và rollback verification.
